# Task Dashboard — One-Click Excel Dashboard (VBA)

**by Muhammad Bilal** · 100% local · No network calls · No API keys · No external files

## The problem

A project management team tracks 40+ tasks in a flat Excel export — one long
list of titles, owners, statuses and due dates. Answering the three questions
management asks every week takes 30–60 minutes of manual work:

1. *How many tasks are overdue, and whose are they?*
2. *What is each owner's completion rate?*
3. *What is due in the next 7 days?*

Copy-paste errors creep in, the numbers differ between meetings, and nobody
trusts the sheet.

## The solution

One macro — **`BuildDashboard`** — reads the `Task Export` sheet and rebuilds
a formatted `Dashboard` sheet in under a second:

| Output | What it shows |
|---|---|
| **KPI tiles** | Total tasks, Completed, In Progress, Overdue, Completion % |
| **Tasks by Owner** | Per-owner total / completed / overdue / completion % |
| **Tasks by Status** | Count + % for Not Started / In Progress / Completed / Blocked |
| **Overdue list** | Every overdue task, red fill, sorted by due date, with days overdue |
| **Due in next 7 days** | Amber fill, sorted by due date, with days left |

Re-run it any time: the Dashboard sheet is deleted and rebuilt from the
current `Task Export` data, so it never goes stale.

## How to run (Excel on Windows)

1. Open `Task-Dashboard.xlsm`.
2. If Excel shows a security warning, click **Enable Content** (the file is
   macro-enabled; the macro only reads/writes inside this workbook).
3. Press **Alt+F8**, select `BuildDashboard`, click **Run**.
4. The `Dashboard` sheet rebuilds instantly.

To use it on your own data: replace the rows in `Task Export` (keep the
header row and column order: Task ID, Title, Project, Owner, Status,
Priority, Due Date) and re-run the macro. Statuses must be one of:
`Not Started`, `In Progress`, `Completed`, `Blocked`.

## How to run (LibreOffice, any OS)

```bash
python3 run_macro.py
```

This executes the macro through the LibreOffice UNO bridge, verifies the
Dashboard KPIs, and rebuilds `Task-Dashboard.xlsm`.

## How it works

```
Task Export (raw rows)
        │  BuildDashboard (VBA)
        ▼
read all rows into arrays → count KPIs → aggregate per owner / per status
→ collect overdue + due-soon lists → sort both by due date
→ delete + rebuild Dashboard sheet → write KPI tiles, tables, coloured lists
```

- **No `WorksheetFunction` / no `Range.Sort` dependency** — all aggregation
  and sorting happens in VBA arrays, so the macro behaves identically in
  Excel and LibreOffice.
- **Error handling** — the main routine has `On Error GoTo ErrHandler`;
  formatting helpers swallow their own errors so a styling quirk can never
  kill the build.
- **Scalable** — the same macro handles 40 tasks or 4,000 (loops are linear;
  the only O(n²) step is the per-owner lookup, negligible at PM scale).
- **Deterministic** — same input → same Dashboard, byte for byte.

40 tasks across 3 fictional projects (`City Lab LIMS Rollout`,
`QMS Digitization`, `Data Migration & Reporting`), 6 owners, all statuses and

## Known limitations (honest)

- **Excel is the intended host.** The embedded VBA project was validated with
  `oletools.olevba` (byte-identical source extraction). LibreOffice can *run*
  the macro (proven via UNO) but its VBA *import* did not load the embedded
  project in this environment, and LibreOffice cannot author VBA projects at
  all — see `TEST-REPORT.md` for the full evidence.
- The macro expects the exact `Task Export` header row and column order.
- Dates must be real Excel dates (not text) for overdue math to work.
- No multi-user / concurrent editing — it is a single-file automation.
